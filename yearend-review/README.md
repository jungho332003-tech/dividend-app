# 연말정산 검토 관리 (Google Sheets + Apps Script 웹앱)

연말정산 담당자들이 서류 검토 진행, 특이사항, 응대 내용을 함께 관리하는 프로그램입니다.
인사팀 업무관리(`weekly-report/`)와 같은 구조로, 구글 스프레드시트를 데이터베이스로 씁니다.

| 메뉴 | 내용 |
|---|---|
| 대시보드 | 긴급·고정 공지 배너, 검토 대상·내가 처리할 대상자·미비서류·2차 대기·완료율, 담당자별 진행, 최근 공지·응대기록 |
| 서류 검토 | **내 담당 / 전체 / 응대기록**. 대상자를 누르면 기존 검토 시트 열 그대로 입력 (진행 체크, 종전근무지, 주택자금·월세, 특이사항·수정사항·미비서류, 2차 검토). 증빙 첨부, 응대기록(전화·메일·방문 등) |
| 공지사항 | 공지·응대지침(총괄), 자료·질문(누구나). 중요도(긴급/중요/일반), 게시 기간, 상단 고정, 사람별 읽음 표시, 댓글로 질문·답변, 메신저용 복사 |
| 연말정산 기준 | 인적공제·주택자금·의료비 등 분류별 기준, 검색, 원문 링크·첨부, 개정 이력. 총괄·관리자만 등록·수정 |
| 첨부파일 | 대상자 증빙·공지 첨부·기준 첨부·일반 자료를 한곳에서 검색, 구글 드라이브에서 열기 |
| 권한 관리 (관리자만) | 담당자 등록(역할·관리자), 담당자별 **열람 범위**(어느 담당자의 대상자까지 볼지), **권한 한 번에 적용**(시트·첨부 폴더 공유 + 시트 보호), 역할별 **메뉴 권한**, 설정, 접속 안내 문구 |

## 역할

| 역할 | 할 수 있는 일 |
|---|---|
| 응대담당 | [대상자] 시트 `담당자` 칸에 내 이름이 있는 사람의 기본 정보·진행·1차 특이/수정사항·미비서류 입력. 담당자가 비어 있는 사람은 「내가 담당하기」로 맡을 수 있음 |
| 2차검토 | `2차검토 담당자` 칸에 내 이름이 있는 사람의 2차 서류검토 여부·특이사항(2차)·수정사항(2차) 입력 |
| 총괄 | 모든 대상자 입력, 담당 배정, 대상자 추가·삭제·**대상자 업로드**(엑셀·CSV·붙여넣기), 공지·응대지침, 연말정산 기준 등록 |
| 관리자 | 권한 관리 메뉴 (스프레드시트 소유자는 항상 관리자). 역할과 따로 줄 수 있음 |

- 응대기록은 담당이 아니어도 누구나 남길 수 있습니다 (전화를 받은 사람이 기록).
- 같은 대상자를 1차·2차 담당자가 동시에 고쳐도 **바뀐 칸만** 저장하므로 서로 덮어쓰지 않습니다.
- 권한은 화면에서 막고, 서버에서도 다시 확인합니다.

### 열람 범위 (담당자별로 볼 수 있는 대상자)

관리자가 **권한 관리 > 열람 범위**에서 담당자마다 정합니다. [담당자] 시트 `열람범위` 열에 저장됩니다.

| 설정 | 보이는 대상자 |
|---|---|
| 전체 | 모든 대상자 |
| 본인 담당만 | `담당자`·`2차검토 담당자` 칸에 내 이름이 있는 사람 |
| 본인 + 고른 담당자 | 내 담당 + 체크한 담당자가 1차 담당인 사람 (예: `본인,이수민`) |
| (미배정) 체크 | 담당자가 비어 있는 사람도 보이고 「내가 담당하기」로 맡을 수 있음 |

- 총괄·관리자는 항상 전체를 봅니다. 열람범위 칸이 비어 있으면 전체로 봅니다 (예전에 만든 시트도 그대로 동작).
- 처음 설치하면 응대담당은 `본인`(내 담당만)으로 시작합니다.
- 범위 밖의 대상자는 서버에서부터 보내지 않습니다. 그 사람의 응대기록·증빙 첨부도 함께 숨겨지고, 저장·응대기록·업로드도 서버에서 막힙니다.
- 대시보드의 진행 현황도 보이는 대상자 기준으로 나옵니다.

## 검토 상태 (자동 판정)

시트에 상태 열을 따로 두지 않고, 체크 항목으로 자동 판정합니다.

| 상태 | 조건 |
|---|---|
| 미비서류 | `미비서류` 칸에 내용이 있음 (가장 먼저 판정) |
| 서류 미도착 | E-HR 등록·서류 도착·수기서류 제출이 모두 비어 있음 |
| 1차 검토중 | 서류는 왔고 `서류확인 및 검증`이 비어 있음 |
| 2차 검토 대기 | 1차 검증 완료, `2차 서류검토 여부`가 비어 있음 |
| 검토완료 | 2차 서류검토까지 체크 |

## 시트 구성

| 시트 | 누가 편집 | 내용 |
|---|---|---|
| 대상자 | 웹앱 (시트에서 직접 고치면 경고만) | 기존 검토 시트 열 35개 그대로 + `최종수정`·`수정자` |
| 응대기록 | 웹앱 | 일시, 사원번호, 성명, 작성자, 구분, 내용 |
| 공지 / 공지댓글 | 웹앱 | 공지·자료·질문과 댓글 |
| 기준 / 기준개정이력 | 총괄·관리자 | 연말정산 기준과 개정 이력 (처음 설치할 때 예시 6건이 들어감) |
| 첨부 | 웹앱 | 올린 파일 기록 (첨부파일 메뉴의 원본) |
| 설정 / 담당자 / 메뉴권한 | 관리자 | 업무명·귀속연도·첨부 폴더, 담당자 명단, 역할별 메뉴 |

**기존 검토 시트를 그대로 쓸 수 있습니다.** [대상자] 시트의 1행 열 이름으로 위치를 찾기 때문에 열 순서가 달라도 되고, 제목에 줄바꿈이 있어도 됩니다. `24년도 장기주택 공제여부(차입일)`처럼 연도가 바뀌는 열도 인식합니다. 체크 칸은 O·Y·○·완료 같은 표기와 체크박스를 모두 읽고, 저장할 때 원래 칸 형식(체크박스면 체크박스, 아니면 O)을 유지합니다.

## 설치 (관리자 1회)

**붙여넣을 파일은 3개입니다** (`dist/` 폴더, 또는 설치 코드 페이지 `dist/install.html`에서 복사).

1. 새 구글 스프레드시트 생성 → **확장 프로그램 > Apps Script**
2. 기본으로 있는 **`Code.gs`** 내용을 전부 지우고 `dist/Code.gs` 전체를 붙여넣기
3. 파일 옆 **+ → HTML** → 이름 `App` → `dist/App.html` 전체를 붙여넣기
4. **⚙ 프로젝트 설정 → "편집기에 appsscript.json 매니페스트 파일 표시"** 체크 → `appsscript.json`을 `dist/appsscript.json`으로 바꾸기 (시간대 Asia/Seoul)
5. 저장 → 스프레드시트 새로고침 → 상단 **🧾 연말정산 > ⚙️ 관리자 설정 > 1. 기본 시트 만들기** → 권한 승인
6. 기존 검토 시트 내용을 [대상자] 시트에 붙여넣기 (제목 행은 이미 있으니 2행부터. 또는 웹앱 서류 검토 > 「대상자 업로드」에서 엑셀 파일 올리기)
7. 구글 드라이브에 증빙용 폴더를 새로 만들기 (담당자에게만 공유할 폴더)
8. 웹앱 배포(아래) 후 웹앱의 **권한 관리** 메뉴에서 설정(첨부 폴더)·담당자 등록·**권한 한 번에 적용**

> 개발용으로는 원본 파일(`*.gs`, `App.html`)을 파일별로 넣어도 똑같이 동작합니다. 원본을 고친 뒤 `python3 build.py`를 실행하면 `dist/`가 다시 만들어집니다.

## 웹앱 배포

1. Apps Script 편집기 > **배포 > 새 배포** > 유형 **웹 앱**
2. **다음 사용자 인증 정보로 실행: 웹 앱에 액세스하는 사용자**
   (접속한 사람의 이메일로 [담당자] 시트에서 이름·역할을 찾고, 공지 읽음 표시도 사람별로 저장됩니다)
3. **액세스 권한**: 회사 구글 워크스페이스면 "조직 내 모든 사용자", 개인 지메일이면 "Google 계정이 있는 모든 사용자"
4. 배포 후 나오는 웹앱 주소를 담당자에게 공유 (권한 관리 > 접속 안내에 안내 문구가 있습니다)
5. 코드를 고친 뒤에는 **배포 관리 > 수정 > 버전: 새 버전**으로 다시 배포해야 반영됩니다.

## 대상자 업로드

총괄·관리자는 **서류 검토 > 대상자 업로드**에서 대상자 명단을 한 번에 올립니다.

- **파일 올리기**: 엑셀(.xlsx, .xls)·CSV 파일. 엑셀은 「성명」 열이 있는 첫 시트를 자동으로 고르고, 맨 위에 제목 줄이 있어도 위쪽 10줄 안에서 열 이름 줄을 찾습니다. CSV는 엑셀 기본 저장 형식(EUC-KR)과 UTF-8 모두 읽습니다.
- **붙여넣기**: 시트에서 제목 행부터 복사해 붙여넣기.
- 열 이름으로 맞추므로 일부 열만 있어도 됩니다(예: No., 부서, 사원번호, 성명, 담당자).
- **빈 칸은 기존 값을 그대로 둡니다** (파일에 없는 열도 마찬가지). 체크 항목은 O로 체크, X로 체크 해제. 글자 칸을 비우려면 웹앱 수정 화면에서 지웁니다.
- 사원번호가 이미 있으면 **갱신**, 없으면 **추가**. 올리기 전에 추가·갱신 인원과 앞 5명을 미리 보여줍니다.
- 파일 안에서 사원번호가 겹치면 알려주고, 아래쪽 줄의 값으로 합쳐 올립니다.
- **양식 다운로드**: 「양식 다운로드」 → 빈 양식(시트와 같은 35개 열 + 작성 안내 시트) 또는 현재 명단 포함(지금 보이는 대상자가 채워진 파일, 엑셀에서 한꺼번에 고쳐 다시 올리기용). 체크 칸은 O/X 목록, 담당자 칸은 [담당자] 이름 목록에서 고를 수 있습니다. 내 구글 드라이브에 「연말정산 대상자 업로드 양식」 시트를 하나 만들어 두고(다음부터 다시 씀) 엑셀(.xlsx)로 새 탭에서 내려받습니다.
- 엑셀 읽기 도구(SheetJS)는 처음 엑셀 파일을 올릴 때 cdnjs에서 한 번 내려받습니다. 회사 망에서 막히면 붙여넣기를 쓰세요.

## 개인정보

- 증빙 서류에는 주민등록번호·병원 기록 등 민감한 정보가 들어 있습니다. 첨부 폴더는 **새 폴더를 만들어 담당자에게만** 공유하세요. 「권한 한 번에 적용」은 [담당자] 시트에 있는 사람에게만 공유합니다.
- 담당자를 뺄 때는 권한 관리에서 × → "스프레드시트·첨부 폴더 접근도 해제"를 체크하세요.
- 메뉴 권한에서 서류 검토를 끈 역할에게는 대상자 정보와 증빙 첨부가 서버에서부터 보내지지 않습니다.
- 첨부 삭제는 드라이브 휴지통으로 옮깁니다 (30일 안에 복구 가능).
- 연말정산이 끝나면 스프레드시트와 첨부 폴더의 공유를 정리하고, 다음 해에는 스프레드시트를 복사해 새로 시작하는 것을 권장합니다.

## 파일 첨부

- **대상자 증빙**(대상자 화면), **공지사항**, **연말정산 기준**, **일반 자료**(첨부파일 메뉴)에 올릴 수 있습니다.
- 대상자 증빙·일반 자료는 올리는 즉시 저장됩니다. 공지·기준 첨부는 글을 저장할 때 함께 저장됩니다.
- 한 파일 **10MB 이하**. 큰 파일은 드라이브에 직접 올리고 링크로 붙여주세요.

## 속도

- **저장은 화면에 바로 반영**됩니다(대상자 검토 내용, 응대기록, 공지·댓글, 기준, 첨부 삭제). 서버 저장은 뒤에서 하고, 그동안 오른쪽 위에 「저장 중…」이 보입니다. 끝나면 "저장했습니다" 알림이 뜹니다.
- 저장에 실패하면 화면을 원래대로 되돌리고, 작성하던 내용을 그대로 다시 띄워 오류와 함께 보여줍니다. 「저장 중…」일 때 창을 닫으려 하면 경고가 나옵니다.
- 서버 쪽 저장도 줄였습니다: 대상자 저장은 행 읽기 1번 + 바뀐 칸 쓰기, 다시 읽지 않음. 설정·담당자 목록은 60초 캐시, 응대기록·댓글은 시트 전체를 다시 읽지 않고 캐시에 바로 넣습니다.
- 화면 데이터는 서버에서 **60초간 캐시**해 담당자 전체가 함께 씁니다. 대상자가 많아도 여러 조각으로 나눠 캐시합니다.
- 스프레드시트에서 직접 고친 내용(대상자·담당자·설정 포함)은 최대 60초 뒤 웹앱에 보입니다.
- 파일 업로드는 파일을 실제로 보내야 하므로 크기만큼 시간이 걸립니다.

## 예시 화면 / 시험

- `dist/demo.html`: 브라우저로 바로 여는 예시 화면 (가짜 데이터 30명, `demo/Mock.js`). 중복공제·맞벌이·외국인·중도입사·주택자금·난임·휴직자 등 응대 사례가 들어 있고, 위쪽에서 보는 사람을 바꿔 역할·열람 범위별 화면을 볼 수 있습니다.
- `node tests/server.test.js`: Apps Script를 흉내 낸 환경에서 `dist/Code.gs`의 서버 함수를 시험합니다 (`python3 build.py` 먼저).
