# dividend-app
## yearend-settlement.html — 연말정산 검토 관리

연말정산 담당자용 업무 보드 (단일 HTML, 브라우저 localStorage 저장)

- **공지사항**: 분류·중요도(긴급/중요/일반)·게시기간·상단고정, 안읽음 표시, 메신저용 복사
- **특이사항**: 직원별/일반 응대 기록, 처리 상태·후속조치 기한, 응대 이력, 담당자 공유, 공지로 전환
- **서류 검토**: 기존 구글 시트 열 구조 그대로 관리 — 시트에서 복사해 붙여넣기로 가져오고, 같은 열 순서의 CSV로 내보내기
- 데이터는 사용 중인 브라우저에만 저장되므로 사이드바의 「백업」으로 주기적으로 보관하세요
