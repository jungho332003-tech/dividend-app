# 인사팀 업무관리 (Google Sheets + Apps Script 웹앱)

구글 스프레드시트를 데이터베이스로 쓰는 팀 업무관리 프로그램입니다. 웹앱 화면은 6개 업무 메뉴와 관리자용 **관리** 메뉴로 구성됩니다.

| 메뉴 | 내용 |
|---|---|
| 대시보드 | 주간보고 마감 D-day, 작성완료 현황, 이번 달 예산전용, 휴무자, 다가오는 일정, 예산 과목별 현재예산, 최근 예산전용·게시글 |
| 주간업무보고 | **내 주간업무**(금주·차주 업무, 기한, 휴무, 작성완료) / **팀 주간보고**(기존 양식 그대로 + 팀장 코멘트) |
| 예산전용 | **신청 내역**(신청자·전출→전입·금액·사유, 신청 즉시 반영, 잘못 신청한 건은 취소) / **예산현황**(과목별 편성·전입·전출·현재예산) |
| 일정 | 팀 구글 캘린더 월간 보기 + 일정 추가. 공휴일과 주간보고 마감도 함께 표시 |
| 공유게시판 | 공지(팀장)·자료·일반 글, 상단 고정, 링크 첨부, 댓글 |
| 관리 (관리자만) | 팀원 등록, **권한 한 번에 적용**(시트·첨부 폴더·캘린더 공유 + 시트 잠금), 팀원별 권한 상태, 역할별 **메뉴 권한**, 설정, 접속 안내 문구 |
| 회사 기준 | 인사·근태/급여·수당/복리후생/출장·경비/교육 분류별 기준, 검색, 원문 링크, 개정 이력. 팀장·관리자만 등록·수정 |

스프레드시트에서 직접 작성해도 되고, 웹앱 화면에서 작성해도 같은 시트에 저장됩니다.

## 시트 구성

| 시트 | 누가 편집 | 내용 |
|---|---|---|
| 주간보고 | 자동 생성 (팀장은 코멘트 칸만) | 이름 / 금주 주요업무·기한 / 차주 주요업무·기한 / 휴무계획·특이사항 / **팀장 코멘트** |
| 입력_이름 (8개) | 본인만 | 금주·차주 업무, 기한(날짜 또는 `지속`), 휴무/특이사항, 작성완료 체크 |
| 예산전용 | 웹앱·메뉴 폼으로 신청 (직접 수정 시 경고) | 신청번호, 신청일시, 신청자, 전출·전입과목, 금액, 사유, 취소(Y) |
| 예산과목 | 관리자 | 과목별 편성액 → 전입·전출·현재예산 자동 계산 |
| 회사기준 / 기준개정이력 | 팀장·관리자 | 회사 기준 본문과 개정 이력 (수정할 때마다 자동 기록) |
| 게시판 / 댓글 | 웹앱에서 작성 (직접 수정 시 경고) | 공유게시판 글과 댓글 |
| 설정 / 팀원 / 공휴일 | 관리자 | 팀명, 이번주 월요일, 마감 예외, 팀 캘린더 ID, 팀원 명단(이메일·역할), 공휴일 |
| 보관_yyyy-MM-dd | 숨김 | 지난 주차 보고서 |

## 설치 (관리자 1회)

**붙여넣을 파일은 3개입니다** (`dist/` 폴더). 스크립트 11개를 `Code.gs` 하나로 합쳐 두었습니다.

1. 새 구글 스프레드시트 생성 → **확장 프로그램 > Apps Script**
2. 기본으로 있는 **`Code.gs`** 내용을 전부 지우고 `dist/Code.gs` 전체를 붙여넣기
3. 파일 옆 **+ → HTML** → 이름 `App` → `dist/App.html` 전체를 붙여넣기
4. **⚙ 프로젝트 설정 → "편집기에 appsscript.json 매니페스트 파일 표시"** 체크 → `appsscript.json`을 `dist/appsscript.json`으로 바꾸기 (시간대 Asia/Seoul, Google Calendar API 고급 서비스 포함)
5. 저장 → 스프레드시트 새로고침 → 상단 **📋 주간업무 > ⚙️ 관리자 설정**
   1. **기본 시트 만들기** → 권한 승인
   2. **자동 실행(트리거) 켜기**
6. 웹앱 배포(아래) 후 웹앱의 **관리** 메뉴에서 설정·팀원 등록·**권한 한 번에 적용**

> 개발용으로는 원본 파일(`*.gs`, `App.html`, `BudgetForm.html`)을 파일별로 넣어도 똑같이 동작합니다. 원본을 고친 뒤 `python3 build.py`를 실행하면 `dist/`가 다시 만들어집니다.

## 웹앱 배포

1. Apps Script 편집기 > **배포 > 새 배포** > 유형 **웹 앱**
2. **다음 사용자 인증 정보로 실행: 웹 앱에 액세스하는 사용자**
   (접속한 사람의 이메일로 [팀원] 시트에서 이름·역할을 찾고, 시트 보호 권한도 그대로 적용됩니다)
3. **액세스 권한**: 회사 구글 워크스페이스면 "조직 내 모든 사용자", 개인 지메일이면 "Google 계정이 있는 모든 사용자"
4. 배포 후 나오는 웹앱 주소를 팀원에게 공유 (스프레드시트 메뉴 **📋 주간업무 > 🌐 업무관리 웹앱 열기**에서도 확인 가능)
5. 팀원은 처음 접속할 때 권한 승인 화면이 한 번 나옵니다.
6. 코드를 고친 뒤에는 **배포 관리 > 수정 > 버전: 새 버전**으로 다시 배포해야 반영됩니다.

## 매주 흐름

| 시점 | 동작 |
|---|---|
| 월 07시 (자동) | 지난주 보고서 보관 → 각자의 **차주 업무가 금주로 이월**, `지속` 업무는 차주에도 유지, 작성완료 체크 해제 |
| 평일 매시간 (자동) | 주간보고 새로고침 (작성완료 미체크자는 이름 칸이 붉게 표시됨) |
| 마감 3시간 전 (자동) | 작성완료 미체크 팀원에게 알림 메일 |
| 마감 후 (자동) | 팀장에게 "취합 완료" 메일 + 미작성자 목록 |
| 수시 | 팀장이 주간보고의 **팀장 코멘트** 칸에 작성 (새로고침해도 유지됨) |

- 마감 기본값은 **목요일 오후 2시**입니다. 목요일이 공휴일이면 직전 근무일로 자동 변경되고, 제목에 `이번주만 9/23 (수) 오후 2시까지`처럼 표시됩니다.
- 그 밖의 예외가 있으면 [설정] > `이번주 마감일시`에 직접 입력하세요. 다음 주차로 넘어가면 자동으로 비워집니다.
- 주차는 **월요일이 속한 달의 몇 번째 월요일인지**로 셉니다. 기간은 공휴일을 뺀 근무일로 표시합니다. 예) `9월 3주 (9/21~9/23)`
- [공휴일] 시트에는 2026년 남은 공휴일과 2027년 공휴일이 들어 있습니다. 정부 발표(임시공휴일 등)에 맞게 확인하고 수정하세요.

## 예산전용

결재 단계 없이 **신청 내역만 기록**합니다. 결재는 회사 전자결재 등 기존 절차를 따릅니다.

1. 팀원: 웹앱 **예산전용 > 예산전용 신청** (또는 스프레드시트 메뉴 **💰 예산전용 신청**)에서 전출·전입과목, 금액, 사유 입력
   - 전출과목의 현재예산을 넘으면 신청할 수 없습니다.
2. 신청하면 바로 [예산과목]의 전입·전출·현재예산에 반영되고, 팀장에게 알림 메일이 갑니다.
3. 잘못 신청한 건은 신청자 본인이나 팀장·관리자가 **취소**합니다. 시트에는 취소(Y)로 남고 예산에서는 빠집니다.

> 이전 버전(결재 기능)으로 이미 만든 시트가 있다면 [예산전용]·[예산과목] 시트를 지우고 "1. 기본 시트 만들기"를 다시 실행하세요.

## 관리 메뉴 (권한)

관리자 = 스프레드시트 소유자 + [팀원] 시트에서 `관리자(Y/N)`가 Y인 사람. 웹앱 왼쪽에 **관리** 메뉴가 보입니다.

| 탭 | 하는 일 |
|---|---|
| 팀원·권한 | 팀원 추가·수정·삭제(이름, 이메일, 역할, 주간보고 작성 여부, 관리자). 팀원별로 스프레드시트·입력시트·첨부 폴더·팀 캘린더 권한 상태를 ✓/✕로 표시 |
| | **권한 한 번에 적용**: 스프레드시트·첨부 폴더 편집자 공유, 팀 캘린더 "일정 변경" 공유, 입력시트 생성, 시트 잠금을 한 번에 처리하고 결과를 보여줌 |
| | 팀원을 뺄 때 스프레드시트·폴더·캘린더 접근도 함께 해제 가능 (소유자·본인은 제외) |
| 메뉴 권한 | 역할(팀원/팀장)별로 볼 수 있는 메뉴를 켜고 끔. 끈 메뉴는 화면에서 숨고 **서버에서도 데이터와 기능이 막힘**. 관리자는 항상 전체 |
| 설정 | 팀명, 마감 시각, 미작성 알림, 팀 캘린더 ID, 첨부 폴더(주소를 그대로 붙여넣어도 됨) + 연결 확인 |
| 접속 안내 | 웹앱 주소와 팀원에게 보낼 안내 문구 복사 |

- 공유할 때 구글이 팀원에게 공유 알림 메일을 보냅니다(캘린더는 알림 없이 공유).
- 캘린더 공유는 **캘린더 소유자(또는 공유 관리 권한자)** 가 실행해야 합니다.

## 파일 첨부

- **공유게시판**(첨부 파일), **회사 기준**(규정 원문 PDF 등), **예산전용**(견적서·품의서 등 증빙)에 파일을 올릴 수 있습니다.
- 끌어다 놓거나 눌러서 선택하면 바로 드라이브에 올라가고, 업로드가 끝나야 등록할 수 있습니다.
- 한 파일 **10MB 이하**. 큰 파일은 드라이브에 직접 올리고 링크 칸에 붙여주세요.
- 첨부 목록은 각 시트의 `첨부` 열에 저장됩니다. 글에서 첨부를 빼도 드라이브의 파일은 지워지지 않습니다.

## 휴대폰

- 화면 폭이 좁으면 자동으로 휴대폰 화면으로 바뀝니다: 아래쪽 탭 바(홈·주간보고·예산·일정·게시판·기준·관리), 표는 카드 형태, 입력창은 아래에서 올라오는 시트.
- 팀 주간보고는 사람별 카드로 보이고, 팀장은 카드 아래 코멘트 칸을 눌러 바로 작성할 수 있습니다.
- **홈 화면에 추가**: 휴대폰 브라우저에서 웹앱 주소를 열고 공유 버튼(아이폰) 또는 ⋮ 메뉴(안드로이드) → "홈 화면에 추가"를 누르면 앱처럼 아이콘으로 열 수 있습니다.

## 속도

- 화면 데이터는 서버에서 **60초간 캐시**해 팀 전체가 함께 씁니다. 메뉴를 옮겨 다닐 때는 서버를 다시 부르지 않습니다.
- 웹앱에서 저장하면 **바뀐 부분만** 다시 읽어 캐시를 바로 고칩니다. 스프레드시트에서 직접 고친 내용은 최대 60초 뒤 웹앱에 보입니다.
- 내 주간업무 저장과 팀장 코멘트는 **누르자마자 화면에 반영**되고 저장은 뒤에서 처리됩니다. 저장에 실패하면 화면을 되돌리고 작성 내용은 그대로 남깁니다.

## 참고
- "주간보고 새로고침"과 "다음 주차로 넘기기"는 보호된 시트를 수정하므로 **관리자(소유자)** 가 실행해야 합니다. 자동 트리거는 관리자 권한으로 실행됩니다.
- [예산전용] 시트의 신청 칸(A~G)은 "경고" 수준으로만 보호됩니다. 직접 수정하면 경고가 뜨지만 막히지는 않습니다.
- 메일은 Apps Script 일일 발송 한도(개인 계정 약 100건)를 사용합니다.
