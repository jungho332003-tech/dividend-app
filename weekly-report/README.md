# 인사팀 주간업무 · 예산전용 (Google Sheets + Apps Script)

팀원 8명이 각자 입력시트에 작성하면 기존 보고 양식대로 **주간보고가 자동 취합**되고, 팀장은 **코멘트 칸**에 의견을 남깁니다.
같은 파일에서 **예산전용 신청 → 팀장 결재 → 결과 메일**까지 처리합니다.

## 시트 구성

| 시트 | 누가 편집 | 내용 |
|---|---|---|
| 주간보고 | 자동 생성 (팀장은 코멘트 칸만) | 이름 / 금주 주요업무·기한 / 차주 주요업무·기한 / 휴무계획·특이사항 / **팀장 코멘트** |
| 입력_이름 (8개) | 본인만 | 금주·차주 업무, 기한(날짜 또는 `지속`), 휴무/특이사항, 작성완료 체크 |
| 예산전용 | 신청: 메뉴 폼 / 결재: 팀장만 | 신청번호, 신청자, 전출·전입과목, 금액, 사유, 결재(승인/반려), 팀장 의견, 처리일시 |
| 예산과목 | 관리자 | 과목별 편성액 → 전입·전출·현재예산·전용가능액 자동 계산 |
| 설정 / 팀원 / 공휴일 | 관리자 | 팀명, 이번주 월요일, 마감 예외, 팀원 명단(이메일·역할), 공휴일 |
| 보관_yyyy-MM-dd | 숨김 | 지난 주차 보고서 |

## 설치 (관리자 1회)

1. 새 구글 스프레드시트 생성 → **확장 프로그램 > Apps Script**
2. 이 폴더의 파일을 같은 이름으로 추가해 붙여넣기
   - `Config.gs`, `Setup.gs`, `Report.gs`, `Automation.gs`, `Budget.gs` (스크립트 파일)
   - `BudgetForm.html` (HTML 파일, 이름은 `BudgetForm`)
   - 프로젝트 설정에서 "appsscript.json 표시"를 켜고 `appsscript.json` 내용 붙여넣기 (시간대 Asia/Seoul)
3. 스프레드시트 새로고침 → 상단 **📋 주간업무 > ⚙️ 관리자 설정**
   1. **기본 시트 만들기** → 권한 승인
   2. [팀원] 시트에 이름·이메일·역할 입력 (팀장은 역할 `팀장`, 작성대상 `N`)
      [예산과목] 시트에 과목명·편성액 입력
   3. **팀원 입력시트 만들기 + 권한 적용**
   4. **자동 실행(트리거) 켜기**
4. 스프레드시트를 팀원 전원과 팀장에게 **편집자**로 공유

## 매주 흐름

| 시점 | 동작 |
|---|---|
| 월 07시 (자동) | 지난주 보고서 보관 → 각자의 **차주 업무가 금주로 이월**, `지속` 업무는 차주에도 유지, 작성완료 체크 해제 |
| 평일 매시간 (자동) | 주간보고 새로고침 (작성완료 미체크자는 이름 칸이 붉게 표시됨) |
| 마감 3시간 전 (자동) | 작성완료 미체크 팀원에게 알림 메일 |
| 마감 후 (자동) | 팀장에게 "취합 완료" 메일 + 미작성자 목록 |
| 수시 | 팀장이 주간보고의 **팀장 코멘트** 칸에 작성 (새로고침해도 유지됨) |

- 마감 기본값은 **목요일 오후 2시**입니다. 목요일이 공휴일이면 직전 근무일로 자동 변경되고, 제목에 `이번주만 9/23 (수) 오후 2시까지`처럼 표시됩니다.
- 그 밖의 예외가 있으면 [설정] > `이번주 마감일시`에 직접 입력하세요. 다음 주차로 넘어가면 자동으로 비워집니다.
- 주차는 **월요일이 속한 달의 몇 번째 월요일인지**로 셉니다. 기간은 공휴일을 뺀 근무일로 표시합니다. 예) `9월 3주 (9/21~9/23)`
- [공휴일] 시트에는 2026년 남은 공휴일과 2027년 공휴일이 들어 있습니다. 정부 발표(임시공휴일 등)에 맞게 확인하고 수정하세요.

## 예산전용

1. 팀원: **📋 주간업무 > 💰 예산전용 신청** → 전출·전입과목, 금액, 사유 입력
   - 전출과목의 **전용가능액**(현재예산 − 결재대기 중인 전출)을 넘으면 신청할 수 없습니다.
2. 팀장에게 결재 요청 메일이 발송됩니다.
3. 팀장: [예산전용] 시트의 **결재** 칸에서 `승인`/`반려` 선택, 필요하면 **팀장 의견** 입력
   → 처리일시가 기록되고 신청자에게 결과 메일이 발송됩니다.
4. [예산과목]의 현재예산에는 **승인된 건만** 반영됩니다.

> 팀장 의견은 결재 칸을 선택하기 **전에** 입력해야 결과 메일에 포함됩니다.

## 참고
- "주간보고 새로고침"과 "다음 주차로 넘기기"는 보호된 시트를 수정하므로 **관리자(소유자)** 가 실행해야 합니다. 자동 트리거는 관리자 권한으로 실행됩니다.
- [예산전용] 시트의 신청 칸(A~G)은 "경고" 수준으로만 보호됩니다. 직접 수정하면 경고가 뜨지만 막히지는 않습니다.
- 메일은 Apps Script 일일 발송 한도(개인 계정 약 100건)를 사용합니다.
